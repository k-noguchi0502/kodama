# 操作方法

kodama のキー操作とマウス操作です。`keybind.lua` で変更・追加・無効化できます
（書き方は [examples/keybind.lua](../examples/keybind.lua)）。

ペイン操作の修飾キーは Alt です（`keybind.lua` の `super = "alt"`）。
`"ctrl"` に戻すことも、`"logo"` で実際の Super キーにすることもできます。
迷ったら `alt+shift+p` でコマンドパレットを開けば、すべての操作をキー表示付きで検索・実行できます。

## ペイン

Hyprland と同じ感覚で操作できます。

| キー | 動作 |
|---|---|
| `alt+enter` | 新しいペイン（フォーカス中のペインを長い辺の方向に分割） |
| `alt+shift+e` | 右に分割 |
| `alt+shift+o` | 下に分割 |
| `alt+q` / `alt+shift+w` | フォーカス中のペインを閉じる |
| `alt+矢印` | その方向のペインへフォーカス移動 |
| `alt+tab` / `alt+shift+tab` | 次 / 前のペインへ |
| `alt+shift+矢印` | ペインをその方向の隣と入れ替える |
| `ctrl+alt+矢印` | 境界線をその方向へ動かす（リサイズ） |
| `alt+shift+z` | フォーカス中のペインだけを表示（もう一度で元に戻す） |
| `alt+shift+a` | 入力をタブ内の全ペインに同時に送る（もう一度で解除）。その間は各ペインが赤い枠で囲まれる |

`alt` を押しながらペインを別のペインへドラッグすると、その 2 つが入れ替わります。クリックのままでは選択になりません。止めたいときは `features.drag_reorder = false` です。

終了時（ウィンドウを閉じたとき、フォーカスが外れたとき、最後のペインが終わったとき）に、タブ・分割・各ペインのディレクトリと、ファイルツリーを開いていたかを設定ファイルの隣の `session` に書き、次の起動で戻します。ツリーの幅も一緒に戻ります。`-e` でコマンドを指定した起動では戻しません。複数のウィンドウは同じファイルを使うので、最後に終了したものが残ります。止めるときは `features.restore_layout = false` です。

### ペインのサイズ変更

キーボードとマウスのどちらでも変えられます。

- **キーボード**: `ctrl+alt+矢印` で、フォーカス中のペインに一番近い、その向きの境界線を矢印の方向へ動かします。Alt だけだとフォーカス移動と同じキーになるので、リサイズだけ Ctrl が残ります。
  1 回で分割の幅（高さ）の 5% ずつ動きます。左右の矢印は縦の境界線、上下の矢印は横の境界線を動かします。
- **マウス**: ペインの間の境界線をドラッグします。境界線の上ではポインタが ↔ / ↕ の形に変わります。
  線そのものだけでなくペイン間の隙間全体（最低でも 8 ピクセル幅）が掴める範囲なので、細い線でも掴めます。

どちらの方法でも、ペインは分割の 5% より小さくはなりません。
ペインを最大化している間（`alt+shift+z`）はサイズを変えられません。

余白は `config.lua` で辺ごとに指定します（論理ピクセル。0 の辺は端や境界線まで伸び、正の値はその分だけ背景が残ります）。
`window.padding` はウィンドウ端と中身の間隔で、`padding_top` / `padding_right` / `padding_bottom` / `padding_left` がその辺だけを上書きします。
`pane.padding` は各ペインのグリッドの内側で、境界線の隙間（`split.padding`）とは別です。
`pane.active_padding` はフォーカス中のペインにだけ足されます。フォーカス枠（`split.highlight`）はその隙間に出ます。
`split.highlight` が `"background"` または `"both"` のとき、`split.highlight_ignores_padding = true` にすると、その背景色が余白も塗って全体（ウィンドウ端と境界線まで）になります。フォーカスがペインでもツリーでも同じです。文字の位置は変わりません。`false` のときはグリッドの範囲だけです。
`split.highlight` が `"border"` または `"both"` のとき、枠は `split.active_border` で指定した太さ（論理ピクセル）の線だけです。0 で枠は出ません。`highlight_ignores_padding` が true のときは、その線が余白の外側に乗り、背景色はその内側だけになります。
キーボードで使うキーは `keybind.lua` の `resize_pane_left` / `resize_pane_right` / `resize_pane_up` / `resize_pane_down` で変更できます。

ファイルツリーの幅も、ツリーにフォーカスがあるとき同じキー（`ctrl+alt+←` / `→`）で変えられます。マウスでは右端をドラッグします（[ファイルツリー](#ファイルツリー)）。

## タブ

タブが 2 つ以上あるとき、ペインの上にタブバーが表示されます（ファイルツリーは上端まで伸び、タブバーはその右から始まります。ペインとペインの仕切り線はタブバーの下端から始まり、その間に隙間はありません。`tab_bar.show` を `"always"` / `"never"` にすると常に表示 / 非表示）。

見た目は `tab_bar.style` で選べます。`"plain"`（間を空けた長方形、既定）、`"powerline"`（矢印でつなぐ）、`"slant"`（斜めの台形）、`"round"`（角丸）。タブはバーの高さと横幅全体を等分します。2つのときはちょうど半分で、左右に二等分したペインの仕切り線と同じ位置です。最大幅を決めたいときは `tab_bar.max_width`（桁数、既定の 0 は制限なし）、色は theme.lua の `tab_bar` / `tab_active` / `tab_inactive` です。

タブの名前は、既定ではそのタブのアクティブなペインの作業ディレクトリ名です（ホームは `~`）。`tab_bar.title = "title"` にすると、プログラムが設定するタイトル（`user@host:~/path` など）になります。名前を変更したタブはその名前のままです。

| キー | 動作 |
|---|---|
| `alt+shift+t` | 新しいタブ |
| `alt+pagedown` / `alt+pageup` | 次 / 前のタブ |
| `alt+1` 〜 `alt+9` | n 番目のタブへ |
| `alt+shift+,` / `alt+shift+.` | 今のタブを左 / 右へ移動 |
| `alt+shift+i` | タブの名前を変更（`enter` で決定、空にするとシェルのタイトルに戻る） |
| `alt+shift+q` | タブを閉じる |

- タブをクリックで切り替え、中クリックで閉じます。少し動かしてドラッグすると並び替えになります。止めたいときは `features.drag_reorder = false` です。
- タブの最後のペインを閉じるとタブも閉じます。

## コピー・貼り付け

| キー | 動作 |
|---|---|
| `alt+c` | 選択中ならコピー。何も選択していなければアプリに送る |
| `alt+v` | シェルでは貼り付け。vim・nano などの全画面アプリにはキーをそのまま送る |
| `alt+shift+c` / `alt+shift+v` | 常にコピー / 常に貼り付け |
| `shift+insert` | プライマリ選択を貼り付け |
| `alt+shift+y` | 直前のコマンドの出力をコピー（シェル統合が必要） |

マウスで選択した文字列はプライマリ選択にも入り、中クリックで貼り付けられます。`Ctrl+C` は割り当てていないので、シェルの割り込みに使えます。

## スクロール

| キー | 動作 |
|---|---|
| `shift+pageup` / `shift+pagedown` | 1 画面ずつスクロール |
| `shift+home` / `shift+end` | 履歴の先頭 / 末尾へ |
| `alt+shift+pageup` / `alt+shift+pagedown` | 前 / 次のシェルプロンプトへ |
| `alt+shift+h` | 履歴全体をページャ（`scrollback_pager`、既定は `less +G`）で新しいタブに開く。ページャを終えるとタブも閉じる |
| マウスホイール | ポインタの下のペインをスクロール（フォーカスしていなくても可） |

プロンプト間のジャンプと直前の出力のコピーにはシェル統合が必要です。`.zshrc` に次を追加します（bash は `.bash` 版）。

```zsh
source ~/.config/kodama/shell-integration.zsh   # examples/ からコピー
```

シェル統合を入れると、新しいペイン・タブ・ファイルツリーがシェルの現在のディレクトリで開くようにもなります。

## 検索

`alt+shift+f` でフォーカス中のペインの履歴を検索します。ペイン下部に検索バーが出ます。止めるときは `features.search = false` です。

| キー | 動作 |
|---|---|
| 文字入力 | 検索語を入力（一致箇所がハイライトされる） |
| `enter` / `↑` | 古い方の一致へ |
| `shift+enter` / `↓` | 新しい方の一致へ |
| `backspace` / `alt+u` | 1 文字削除 / 全部消す |
| `alt+v` など | 貼り付けた文字列で検索 |
| `esc` | 閉じる |

## コピーモード

`alt+shift+x` で、キーボードだけで履歴を移動して選択・コピーできます（vim 風）。止めるときは `features.copy_mode = false` です。
ペイン下部にモード表示（COPY / VISUAL / VISUAL LINE）と現在行が出ます。

| キー | 動作 |
|---|---|
| `h` `j` `k` `l` / 矢印 | 1 文字・1 行移動 |
| `w` / `b` / `e` | 次の単語 / 前の単語 / 単語の末尾 |
| `0` / `^` / `$` | 行頭 / 最初の非空白 / 行末 |
| `gg` / `G` | 履歴の先頭 / 末尾 |
| `H` / `M` / `L` | 画面の上端 / 中央 / 下端 |
| `alt+u` / `alt+d` | 半画面上 / 下 |
| `alt+b` / `alt+f`、`pageup` / `pagedown` | 1 画面上 / 下 |
| `v`（または `space`） | 文字単位の選択を開始・終了 |
| `V` | 行単位の選択を開始・終了 |
| `y` / `enter` | コピーして終了（未選択ならカーソル行をコピー） |
| `/` | 検索（`esc` で検索を閉じると一致位置から続行） |
| `esc` | 選択中なら選択解除、そうでなければ終了 |
| `q` | 終了 |

## クイックセレクト

`features.quick_select = false` でこのモード自体を止めます。

`alt+shift+space` で、画面に見えている URL・ファイルパス・git ハッシュ・UUID・IP アドレス・
4 桁以上の数字にラベル（`a`、`s`、`d`…、多いときは 2 文字）が付きます。

| キー | 動作 |
|---|---|
| ラベルを入力 | その文字列をコピー（クリップボードとプライマリ選択） |
| ラベルを **大文字で** 入力 | コピーしてシェルに貼り付け |
| `alt` + ラベル | URL ならブラウザで、ファイルなら `$EDITOR` で、ディレクトリなら `cd` で開く |
| `backspace` | 入力したラベルを 1 文字戻す |
| `esc` | キャンセル |

同じ文字列が複数あるときは同じラベルになります。`alt` + ラベルで開くのを止めるときは `features.quick_select_open = false` です。

## コマンドパレット

`alt+shift+p` で画面中央にパレットが開きます。止めるときは `features.command_palette = false` です。すべてのアクション、タブ移動、カラースキーム、言語が並び、
あいまい検索で絞り込めます（右側に割り当てキーを表示）。

| キー | 動作 |
|---|---|
| 文字入力 | 絞り込み |
| `↑` / `↓`、`alt+p` / `alt+n`、`alt+k` / `alt+j`、`tab` | 選択を移動 |
| `pageup` / `pagedown` | 8 項目ずつ移動 |
| `backspace` / `alt+u` | 1 文字削除 / 全部消す |
| `enter` | 実行 |
| `esc` / `alt+shift+p` | 閉じる |

*Color scheme: …* を選ぶとその場で配色が切り替わり、`theme.lua` の `color_scheme` に保存されます
（次回の起動でもその配色になります。`theme.lua` が無ければ作成します）。
保存されるのはスキーム名だけで、`theme.lua` の他の内容（コメント、`colors` の上書き、自作スキーム）はそのまま残ります。

*Language: …* を選ぶと表示言語が切り替わり、`config.lua` の `language` に保存されます。
同梱は `en`（English）と `ja`（日本語）です。インストールすると
`share/kodama/lang/`（pacman なら `/usr/share/kodama/lang/`）に置かれます。
読み込まれるのは選んだ言語のファイルだけで、一覧（`lang/index.lua` とファイル名）以外の
翻訳ファイルは開きません。`~/.config/kodama/lang/ja.lua` のように置くと同梱のファイルより優先されます。
`config.lua` に `language = "ja"` と書いても同じです。

## ファイルツリー

`alt+shift+b` でフォーカス中のペインのディレクトリをサイドバーに表示します。
ツリーにフォーカスがあるときにもう一度押すと閉じます。左端のペインで `alt+←` を押してもツリーに移れます。
開いたまま終了すると、次の起動で同じ幅で戻ります。止めるときは `features.file_tree = false` です。

| キー | 動作 |
|---|---|
| `j` / `k`、`↓` / `↑` | 移動 |
| `l` / `enter` | フォルダを開く。ファイルで `enter` ならペインで環境変数 `EDITOR` のエディタを起動（未設定なら `vi`） |
| `h` | フォルダを閉じる |
| `space` | フォルダの開閉 |
| `g` / `G` | 先頭 / 末尾 |
| `.` | 隠しファイルの表示切り替え |
| `r` | 再読み込み |
| `c` | シェルをそのディレクトリへ `cd` |
| `s` | 隣にペインを作って開く（フォルダは `cd`、ファイルは `$EDITOR`） |
| `i` | パスをシェルに入力 |
| `y` | パスをコピー |
| `/` | 名前で絞り込み（`enter` で確定、`esc` で解除） |
| `a` | 新規作成（`/` で終わるとフォルダ） |
| `R` / `m` / `C` | 名前変更 / 移動 / コピー |
| `d` / `D` | ゴミ箱へ / 完全に削除 |
| `esc` / `q` | ペインに戻る |

`s` を止めるときは `features.tree_open_split = false` です。

git の変更は色と M / A / ? / D / R / U の印で表示されます。
マウスではクリックで選択、フォルダはクリックで開閉、ファイルはダブルクリックで開きます。

### ツリーのサイズ変更

キーボードとマウスのどちらでも変えられます。キーボードは、ツリーにフォーカスがあるときにペインと同じキーを使います。

- **キーボード**: `ctrl+alt+←` / `ctrl+alt+→` で、ツリーとペインの境界をその方向へ動かします。
  1 回でウィンドウ幅の 5%（最低 1 列）ずつ変わります。`←` で狭く、`→` で広くなります。
- **マウス**: ツリーの右端をドラッグします。境界の上ではポインタが ↔ の形に変わります。
  線そのものだけでなくペインとの隙間全体（最低でも 8 ピクセル幅）が掴める範囲なので、細い線でも掴めます。

幅は 8 列以上、ウィンドウの半分以下です。
キーやドラッグで決めた幅は、設定の `tree.width` を書き換えるまで再読み込みしても保たれます。
キーはペインのリサイズと共通で、`keybind.lua` の `resize_pane_left` / `resize_pane_right` です。
`tree.width` は列数のままです。サイドバー内の余白は `tree.padding`（辺ごとに `padding_left` など）、ツリーとペインの間は `tree.gap` です。
`tree.gap` を書かないときは `split.padding` と同じ隙間になります。

## フォントサイズ・設定

| キー | 動作 |
|---|---|
| `alt+=` / `alt++` | 文字を大きく |
| `alt+-` | 文字を小さく |
| `alt+0` | 元の大きさに戻す |
| `alt+shift+r` | 設定を再読み込み（保存時にも自動で読み直す） |
| `f11` | フルスクリーンの切り替え |
| `alt+shift+n` | 新しいウィンドウ（同じ設定、今のペインのディレクトリで開く） |

余白のキーは [examples/config.lua](../examples/config.lua) の `window`、`split`、`pane`、`tree` にあります。保存すれば読み直されます。

背景画像（PNG）は `window.background_image` に指定します。`background_image_opacity`（0〜1、既定 0.25）で背景色からの透け具合を、`background_image_fit` で収め方（`cover` 切り抜いて全体を覆う／`contain` 画像全体を表示／`stretch` 引き伸ばす）を選べます。文字や色付きのセルは画像の上に描かれます。

## マウス

| 操作 | 動作 |
|---|---|
| 左ドラッグ | 文字列を選択（プライマリ選択に入る） |
| 中クリック | プライマリ選択を貼り付け |
| `alt` + クリック | リンクを開く（URL と OSC 8 ハイパーリンク。`alt` を押している間は下線表示） |
| タブをドラッグ | タブを並べ替える |
| `alt` + ペインをドラッグ | ドロップしたペインと入れ替える |
| ホイール | ポインタの下のペインをスクロール |
| 境界線をドラッグ | ペインのリサイズ |
| ツリーの右端をドラッグ | ファイルツリーの幅を変更 |
| クリック | そのペインにフォーカス |

vim や htop などマウスを使うアプリの中では、クリックやドラッグはアプリに送られます。
`shift` を押しながら操作すると kodama 側の選択になります。

## ウィンドウを閉じるとき

最後のペイン・タブを閉じる、またはウィンドウを閉じようとすると、画面下部に確認バーが出ます。

| キー | 動作 |
|---|---|
| `y` / `enter` | 閉じる |
| それ以外 | キャンセル |

ウィンドウの閉じるボタン（ウィンドウマネージャの close）を 2 回続けると確認なしで閉じます。
確認が不要なら `config.lua` で `confirm_close = false` にします。

## ベルと通知

- ベル（`printf '\a'` など）が鳴ると、そのペインが一瞬光ります（`bell.visual`）。
  ウィンドウが非アクティブならウィンドウマネージャに通知します（`bell.urgent`）。
  `bell.command` を設定すると、鳴るたびにそのコマンドを実行します（音を鳴らすなど。0.5 秒に 1 回まで）。
- 別のタブで鳴ったときは、そのタブにベルの印が付きます。タブに切り替えると消えます。
- プログラムが OSC 9 / OSC 777 で送る通知は、`notify-send` でデスクトップ通知になります。
  通知をクリックすると、そのペイン（別のタブならそのタブ）に戻ります。戻るだけを止めるときは `features.notification_focus = false` です。
  `notifications` を `"unfocused"` にするとウィンドウかペインが非アクティブのときだけ、`"never"` で表示しません。
  例: `printf '\e]777;notify;ビルド;完了しました\e\\'`

## examples/keybind.lua で追加される操作

[examples/keybind.lua](../examples/keybind.lua) をコピーした場合は、次の操作も使えます。

| キー | 動作 |
|---|---|
| `alt+shift+q` | タブを閉じる |
| `shift+enter` | `ESC` + `Enter` を送る（改行入力用） |

| `alt+shift+\` / `alt+shift+-` | 右 / 下に分割（tmux 風） |
